# ELTE Data Science & Machine Learning Projects

A collection of academic projects, coursework, programming exercises, and practical implementations developed during my studies at **Eötvös Loránd University (ELTE)**.

This repository documents my learning journey across data science, machine learning, deep learning, and related computational fields. It brings together course assignments, experimental implementations, data analysis workflows, and project-based applications, with an emphasis on understanding concepts through hands-on practice.

## About This Repository

The repository serves as a central place to organize and document projects developed throughout my university studies. It includes both foundational exercises and more advanced implementations, covering different stages of the data science and machine learning workflow — from exploring and analyzing datasets to building models, processing signals, and implementing neural network architectures.

Each project is organized into its own directory where possible, with relevant source code, notebooks, datasets or configuration files, visualizations, and documentation.

## Areas of Study

### 1. Deep Learning & Neural Networks
Projects and practical implementations exploring neural network architectures, model training, and deep learning applications.

Topics include:
- Multilayer perceptrons (MLPs)
- Iris flower classification
- Image captioning
- Transformer components, including positional encoding, scaled dot-product attention, and multi-head attention
- Solar energy forecasting using weather and environmental data

### 2. Data Science & Data Mining
Projects focused on exploratory data analysis, statistical investigation, data preprocessing, and machine learning applications.

Topics include:
- Exploratory data analysis and data visualization
- Data mining coursework
- Obesity data analysis
- Credit default data analysis and related exercises

### 3. Audio Analysis & Signal Processing
Practical exercises exploring the mathematical and computational foundations of digital signal processing.

Topics include:
- Waveform generation and analysis
- Sampling, the Nyquist theorem, and aliasing
- Composite sinusoidal signals
- Fast Fourier Transform (FFT)
- Spectral leakage and frequency resolution

### 4. Image Analysis
Exercises and implementations exploring image processing techniques, including filtering and image manipulation.

## Technologies & Tools

Depending on the project, this repository uses or explores:

- **Python** for scientific computing and implementation
- **Jupyter Notebook** for interactive experimentation
- **NumPy** for numerical computation
- **Pandas** for data manipulation and analysis
- **Matplotlib** and other visualization tools for plotting and reporting
- **Machine learning and deep learning frameworks** for model development
- **Git and GitHub** for version control and project organization

Specific dependencies may vary between projects. Please refer to each project's documentation or requirements file for its setup instructions.

## How to Explore

1. Browse the topic-specific directories to find a project of interest.
2. Read the corresponding `README.md` for an overview, objectives, and instructions.
3. Open the Python scripts or Jupyter notebooks to explore the implementation.
4. Check available figures, reports, and configuration files to understand the results and workflow.
